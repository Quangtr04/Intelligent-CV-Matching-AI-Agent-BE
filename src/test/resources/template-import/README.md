# Legacy Word conversion fixture

`poi-simple.doc` is the unmodified `simple.doc` test fixture from Apache POI:

- Source: https://github.com/apache/poi/blob/trunk/test-data/document/simple.doc
- Downloaded: 2026-10-24.
- SHA-256: `4876e828e62d490fa188c7c4e47013e2e0dfdf02f5903dfd374bc0d2b2049ca1`.
- License and notices: `APACHE-POI-LICENSE` and `APACHE-POI-NOTICE`, copied from the upstream `legal/` directory.

It verifies that a real OLE2 `.doc` file produces editable HTML. It contains public test data and is never used as a product CV template. PDF and DOCX fixtures are generated by the tests themselves.
